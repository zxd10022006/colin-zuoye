## 正则表达式

​     经典的数据匹配查询技术， 内部使用贪心算法完成对数据集快速的模式查询， 相比传统的字符串处理str函数，  正则表达式的效率更高， 匹配速度更快， 而且支持模糊查询， 真正意义上str相关函数不算是数据匹配技术, 正则技术的核心是数据匹配， 但是功能还是很多样的

> 正则表达式技术，非常依赖数据规则， 规则越明确， 正则编写越简单， 如果数据无需存储 没有任何存储规则， 那么无法使用正则表达式
>
> ```<>
> 张三：25：男：北京朝阳区
> 李四：36：女：哈尔滨南岗区
> * 无格式存储， 正则技术几乎无法有效查询
> <name>张三</name> <age>25</age><addr>北京朝阳</addr>
> <name>[^<]+</name>
> ```
>
> 

#### 正则表达式的使用：

* 首先根据数据规则编写正则语句， 一个由基础表达式和符号表达式构成的字符串， 这个字符串用来描述用户要匹配的数据规则和基本特征， 后续使用这个字符串对数据进行模糊查询
* 学习掌握编写正则表达式
  * 正则元符号，一系列的特殊符号
* 正则表达式的匹配过程
* 使用正则技术的两种方式
  * grep ,  命令使用正则表达式
  * 函数， 代码中使用函数， 使用正则技术

##### 正则元符号

> 正则表达式很多特殊符号与通配符相同， 但是含义完全不同, 表达式默认的颗粒度是一个字符， 某些符号需要参照物，默认一个字符

* \ 转义符， 因为正则元符号特殊符号比较多， 很多时候需要转义， 否则正则符号每效果，导致匹配不到结果
* \*  以前一个表达式为参照， 表示该表达式出现0次或多次， 例如 a*  ,  如果使用a直接查询数据， 导致查询次数变多， 效率低下
* \+ 以前一个表达式为参照， 表示该表达式出现1次或多次 例如 a\\+   `需要转义` , 与aa* 完全等价

* .  表示任意的一个字符出现1次， 空符号不可以， 例如换行，缩进等等

  ```c
  https://www.baid.com
  grep 'https://www\.[^\.]+\.com' file  #再匹配数据包含.的时候 表达式中的.需要转义
  ```

  

* ^ 以后一个表达式为参照， 该表达式字符为行首字符，  例如 ^n

* $ 以前一个表达式为参照， 该表达式字符为行尾字符  例如  o$

  * ^$ ,  表达式相互之间无法参照， 这个表达式是匹配空行， 我们可以再grep -n 查看结果行号

    ```c
    ho
    heo
    heeo
    heeeo
    heeeeo
    heeeeeo
    #匹配所有h开头o结尾的内容  grep  '^h.*o$'  test.tx
    ```

    

* [] 表达式集合，  每次使用集合时会在集合中选中一个表达式进行匹配 例如 [abc]

  ```c
  aood
  bood
  cood
  abdood
  grep '[a|b|d]ood' ,表达式最小颗粒度是字符， 也就是一个字符集合。里面或关系
  ```

  * 常用的集合  [a-z]  [A-Z]  [0-9]   [a-zA-Z0-9]有效字符集合
  * [^表达式] , 取非， 匹配所有非表达式的任意数据

* () 作用是创建表达式， 可以提升表达式的颗粒度， 将一个字符变为一个单词 `需要转义`

  ```bash
  grep 'descritpion*' file
  grep '\(description\)*' 匹配这个词0次或多次， 颗粒是一个词
  ```

  

* {} 以前一个表达式为参照， 表示该表达式连续出现的次数  例如 a{2} `需要转义`
  * a{n}   a{n,}   a{n,m} , 例如nm, a最少连续出现n次，  最大连续出现m次, 匹配时按m->n去匹配出现次数
* ?  跟在+ 或者 * 之后， 用于切换匹配模式 ， 可以再贪婪模式和非贪婪模式间切换  `需要转义`

* 正则Regex技术， 使用贪心算法进行模式匹配，速度更快

  * 贪心算法具备不可回溯性， 如果前面的匹配出现异常， 也能持续向后进行，无法回溯检测处理异常
  * 贪心算法以获取局部最优解的方式， 妄图得到全局最优解， 很多时候得不到全局最优解

  ```
  商店的收银员 给顾客找钱，  找钱37元， 每次找钱一个面值， 多少次可以找完
  100  50  20  10  5  1
  20->10->5->1->1
  
  一个人有一个10公斤背包， 面前面前有一些商品货物， 以背包容纳最大容量， 拿到最高价值物资
  6斤=6000
  3斤=3000
  2斤=2000
  2斤=2000
  * 这种问题交给贪心算法 最优解 622,  但是贪心模式63
  ```

  * 贪心模式的编写

    ```bash
    grep '.* '  #以贪婪模式 匹配任意字符1次或多次  '.+' 以贪婪模式匹配任意字符1次多次
    ```

    ```c
    <div>内容A</div>垃圾数A<div>内容B</div>垃圾数据B<div>内容C</div>
        '<div>[^<]\+</div>' = <div>内容A</div>垃圾数A<div>内容B</div>垃圾数据B<div>内容C</div>
        这个表达式匹配的结果异常， 需要处理， 表达式的结果一定要精准, 贪婪模式匹配一次返回n个结果
    <div>[^<]\+\?</div>  <div>[^<]*\?</div> 匹配[^<]任意字符， 非贪婪模式匹配1次或多次, 每次匹配搭配一个结果立即返回， 后续命令会自定进行下次匹配， 相比贪婪模式匹配次数更多， 速度更慢， 但是准确度高
    ```




##### 函数使用正则

> 函数使用正则， #include <regex.h>

* 正则转换， 将字符串的正则表达式转换为正则类型 regex_t

  ```c
  regcomp(regex_t * reg , char * regstr , 0);//将字符串的表达式regstr, 转换为正则类型存储在reg变量， 后续使用reg变量去查询数据
  ```

* 释放正则类型， 避免内存泄漏

  ```c
  regfree(regex_t * reg); //使用完毕释放正则类型
  ```

* 正则表达式语法检查， 抛出表达式的异常

  ```c
  regerror(regex_t * reg , char * error_buff);//检查reg中的正则语法， 如果有异常将异常抛出到error_buff中
  ```

* 使用reg正则类型，进行模式匹配， 每次调用匹配一条结果立即返回， 需要用户循环调用

  ```c
   //数据源： 文件数据（open/read）  外部输入(stdin)   程序参数，  内存数据
  ./app ad 20 8
  int  main(int argc , char ** argv)
      argc = 参数数量(4)
      argv[0]="./app"  argv[1]="ad" argc[2]="20" argv[3]="8"
   regexec(regex_t * reg , void * data,int regnum , regmatch_t * match ,  0); //匹配函数
  * regexec函数匹配到结果会标记数据位置， 用户需要按位置自行提取
  ```

  * reg:  正则类型中存储表达式， 后续使用此正则类型对数据源进行模式匹配

  * data:  数据源， 也是目标数据， 表达式从数据源中查找结果

  * regnum:  表达式数量

  * match:  当regexec匹配到数据后， 将父子表达式的位置存储再数组中 ， 0存储父表达式位置， 后面是子表达式， 后续根据这些位置偏移或提取数据

  * return : 匹配成功返回0 ,  失败返回 REG_NOMATCH       while((regexec())==0)

    ```bash
    <name>刘备</name>
    grep '<name>([^<]\+\?)</name>' file  #模糊查询， name标签中的所有人名
    网页的源码语言 html(超文本标记语言)
    超链接标签   <a href="https://www.baidu.com">点击访问百度</a>
    <a href="([^"]+?)">([^<]+?)</a>
    一般描述数据规则的表达式为父表达式，  后续想提取的关键内容为子表达式, 子表达式的创建使用()包含，  比正则语句中表达式的数量是n(括号的数量)+1,  子表达式的顺序取决于括号出现的位置]
    传出的位置数组 match长度是表达式数量,  这个数组可以存储的位置的总数 是表达式数量 * 2
    ```

  * 关于转义符的数量

    ```c
    <name>[^<]\\+\\?</name>
    ```

    

* 如何快速的加载外部数据到程序中

  * 使用mmap 文件映射手段， 快速将磁盘数据加载到进程内存中， 便于后续处理(一次映射适用于小文件)

    ```c
    #include <sys/mman.h>
    #include <sys/types.h>
    #include <sys/stat.h>
    #include <fcntl.h>
    #include <unistd.h>
    #include <stdio.h>
    #include <stdlib.h>
    #include <string.h>
    #include <regex.h>
    
    int main(void)
    {  
        //1. 打开映射文件
        int fd = open("a.html",O_RDWR);
        //2.获取文件大小
        int fsize = lseek(fd,0,SEEK_END);
        //3.文件映射
        char * mmap_ptr = NULL;
        mmap_ptr = mmap(NULL,fsize,PROT_READ|PROT_WRITE,MAP_PRIVATE,fd,0);
        close(fd);
       
        映射成功 mmap_ptr指向的映射内存， 包含文件的所有数据，  mmap_ptr即是数据源
    
    }
    ```

一共三种标签类型

#### 第一种

普通链接

```c

```

#### 第二种

href前面带有class的 

```c
<a class="ptv" href="//www.chinanews.com.cn/sh/shipin/cns-d/2026/09-17/news1069196.shtml"> 中国成功发射天仪51、52星</a>
```

#### 第三种

没有标题的

```c
<a href="/iframe/2026/09-17/10698191.shtml"></a>
```



最后的正则表达式

```bash
<a[[:space:]]+[^>]*href=\"([^\"]+)\"[^>]*>([^<]*)<"
```

- [[:space;]]+解决正好遇到转行的

- [^>]* 解决的是class问题

- ```bash
  href=\"([^\"]+)\"
  ```

  解决的是网址

- ```ba
  [^>]*
  ```

  解决的是href后面 >前面的东西

- ```ba
  >([^<]*)<
  ```

  中间的就是标题

这样就可以得到就可能多的网址和标题了
